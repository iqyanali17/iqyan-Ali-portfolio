## 🛠 Tech Stack

| Technology | Purpose |
|------------|----------|
| **React 19** | Component-driven UI architecture |
| **Vite 8** | Ultra-fast build tool and dev server |
| **GSAP (GreenSock)** | Smooth cinematic page transitions, ScrollTrigger motion effects |
| **AOS** | On-scroll element entrance reveals |
| **Vanilla CSS** | Tailored design system, responsive styles, and glassmorphic micro-interactions |

---

## 🚀 Key Features

*   **Futuristic Aesthetic UI/UX**: Premium high-contrast layout tuned for software engineering presentation.
*   **Fully Responsive Layout**: Optimised across all screens (Mobile, Tablet, Laptop, and 4K displays).
*   **Smooth Motion & Transitions**: Synchronized GSAP ScrollTrigger timeline transitions that repeat seamlessly upon scrolling.
*   **Speed & Accessibility**: Lazy loading, code splitting, layout shift prevention, and semantic accessible markup.

## 📁 Project Directory Structure

```text
iqyan-portfolio/
├── index.html          # Main HTML entry point
├── README.md           # Documentation
├── package.json        # Project metadata and dependencies
├── package-lock.json   # Package lock configuration
├── vite.config.js      # Vite build configuration
├── public/             # Static public assets (images, icons, resume)
└── src/                # Application source code
    ├── components/     # Modular React components
    ├── data/           # Portfolio content & project data
    ├── App.jsx         # Root application layout
    └── main.jsx        # App mount and entry
```

## 💻 Local Setup & Execution

### 1. Clone the repository
```bash
git clone https://github.com/iqyanali17/iqyan-portfolio.git
cd iqyan-portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
